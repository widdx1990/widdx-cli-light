# WIDDX Roadmap — Competing with Claude Code

## Phase 1: Foundation (1-2 weeks) ← STARTING NOW
- [ ] Smart Read: line numbers, offset/limit, syntax context
- [ ] Smart Edit: diff preview, multiple replacements, undo
- [ ] Context Window: sliding window, structured summarization
- [ ] CLI Framework: subcommands, autocomplete, --help
- [ ] Memory System: MEMORY.md frontmatter, cross-links
- [ ] Permission System: granular allow/deny/ask per tool

## Phase 2: Agent System (2-3 weeks)
- [ ] Workflow Engine: agent(), parallel(), pipeline()
- [ ] Sub-agents: isolated processes, shared context
- [ ] Git Integration: diff review, branch management
- [ ] Task Tracking: structured todo lists inside sessions

## Phase 3: MCP Ecosystem (2 weeks)
- [ ] Auto-discovery: scan registry for MCP servers
- [ ] Dynamic Loading: hot-add/remove servers
- [ ] OAuth Flow: interactive auth for protected servers
- [ ] Error Recovery: auto-reconnect, fallback tools

## Phase 4: Intelligence Layer (3-4 weeks)
- [ ] LLM Classifier: replace keyword matching
- [ ] Planner Integration: steps actually guide execution
- [ ] Knowledge Graph: execution history → better routing
- [ ] Self-improvement: learn from mistakes

## Phase 5: Ecosystem (2+ months)
- [ ] VS Code Extension
- [ ] GitHub App (PR review, issues)
- [ ] CI/CD Pipeline
- [ ] Team Features (shared sessions, project config)
